# Finance Analysis Dashboard | Power BI

## Project Overview

Developed an interactive Finance Analysis Dashboard using Microsoft Power BI to analyze business financial performance, sales trends, and profitability.

The dashboard provides insights into sales, profit, cost of goods sold (COGS), units sold, product performance, country-wise sales, and customer segments.

The report is organized into three pages: Home, Sales Analysis, and Profit Analysis.

## Tools & Technologies
- Microsoft Power BI
- DAX
- Data Visualization
- Financial Data Analysis

## Dashboard Pages

### 1. Home
Provides the main navigation and an overview of the finance report.

### 2. Sales Analysis
Focuses on evaluating sales performance through:
- Sales Trends
- Sales by Country
- Sales by Customer Segment
- Sales by Product
- Units Sold Analysis
- Sales and Profit Comparison by Year

### 3. Profit Analysis
Focuses on understanding business profitability through:
- Monthly Profit Trends
- Profit by Product
- Profit by Customer Segment
- Top 5 Products by Profit
- Profit Margin Analysis
- Cost of Goods Sold (COGS)

## Key Financial Metrics
- Total Sales
- Total Profit
- Total COGS
- Units Sold
- Average Sales
- Profit Margin

## Project Objective

The objective of this project is to analyze business financial performance, understand sales and profitability trends, identify profitable products and customer segments, and generate meaningful insights to support data-driven business decisions.

## Repository Contents

## How to View
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Navigate through the Home, Sales Analysis, and Profit Analysis pages.
4. Explore the visualizations and available filters.

## Note
The Power BI report contains the data model used for the analysis. The dashboard can be explored using Power BI Desktop.
